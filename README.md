# LAWAL.UK

Private family webapp for the Lawal family.

This application uses the proven SORO interface as its initial technical foundation while maintaining a separate LAWAL.UK identity and repository.

## Rebrand foundation

- LAWAL.UK branding and LAWAL.png logo
- Nigerian green, heritage gold and black visual identity
- Family-focused terminology
- Family Circle and Family Groups
- Existing SORO Firebase configuration intentionally retained temporarily; dedicated LAWAL Firebase migration is a separate stage.
